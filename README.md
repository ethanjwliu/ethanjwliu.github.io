# Ethan Liu — Research Portfolio

Personal research and policy portfolio for Jiawei “Ethan” Liu at Rutgers Business School.

The site is plain HTML, CSS, and JavaScript. Serve the repository root with any static web server, for example `python3 -m http.server 8000`. GitHub Pages serves the site at https://ethanjwliu.github.io/.

- `index.html` contains the profile, education, experience, contact information, and page structure.
- `app.js` contains the research records, home page selection, publications, and methods. Each project has a stable ID used for links such as `#research/political-signaling`.
- `styles.css` sets typography, layout, and responsive behavior. The fonts and their licenses are in `fonts/`.
- `portrait.webp` is a smaller version of the original `headshot.jpg`. The résumé and North Dakota funding report are linked directly from their PDFs.
